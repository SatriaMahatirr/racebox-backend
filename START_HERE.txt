🐛 TROUBLESHOOTING:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ Error: View 'garage_owners_summary' doesn't exist
   → Jalankan migration lagi:
     mysql -u root -p racebox < database/migration-garage-owners.sql

❌ Error 401 saat POST vehicle
   → Check JWT token
   → Check middleware auth
   → Login ulang

❌ Motor tidak muncul di garasi per pemilik
   → Check user role = 'pengguna' (bukan 'admin')
   → Check user_id valid
   → Query manual: SELECT * FROM garage_owners_summary;

❌ Page error 500
   → Check server logs
   → Check MySQL connection
   → Restart server
